# Raktárkezelő alkalmazás

Egy egyszerű, Windows Forms alapon készült asztali raktárkezelő program, amit a technikumi képzésem alatt készítettem C# nyelven.

Mit tud a program?
Bejelentkezési felület (felhasználónév és jelszó)
Termékek hozzáadása, törlése és áttekintése (név, ár, darabszám)
Összérték automatikus kiszámítása
Adatok mentése és betöltése szöveges fájlból (`.txt`)
Exportálás funkció

Használt technológiák
C#
NET Windows Forms
Visual Studio
